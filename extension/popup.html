GUIDE quick start
• Click Enable Microphone → Allow mic when prompted.
• Toggle listening anytime with Alt+Shift+V.
• Say down · up · page down · top · bottom.
• Quantifiers: down three, down a little, half page, all the way down.
• Auto-scroll: keep scrolling down → faster / slower → stop.
• Pause with sleep · resume with wake up.
• Works on any website, including pages that scroll inside frames.
• Native PDFs & embedded files: enabling on a PDF switches to PDF mode — a tiny voice hub listens while scrolling is driven through the browser's trusted input engine. First run shows a small “debug” bar briefly; it disappears when it stops.
• Local PDFs (file://): PDF mode does not need “Allow access to file URLs” — but .html files on disk do.
• Edge: speech uses Edge's own speech service; if a language is refused, retry with English (US) or update Edge.
• Note: Chrome/Edge settings & web-store pages block all extensions.
Speech runs through Chrome's / Edge's built-in speech service — no API key
